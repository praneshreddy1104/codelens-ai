🔍 How it works

① Paste your Python code — a program with a while loop.
② Logic check — the AST engine splits your code into the three Gries states and reports logical errors with the exact line & state (S / T / E), then auto-corrects them.
③ ML AST analysis — the corrected code is classified by 6 trained models (seed 2023, stratified 80/20) over the 7 Gries labels, with matplotlib bar charts.
④ History — every analysis is saved to your profile.

🧠 The Gries state model

n = 10 ← S Initial state total = 0 ← S (precondition: variables before the loop) i = 1 ← S while i <= n: ← E Final state (loop condition) total += i ← T Transformation (invariant update) i += 1 ← T print(total) ← E Final state (result after the loop)

Errors in S = wrong initialization, errors in T = wrong update inside the loop, errors in E = wrong loop boundary / final result.
