Dataset

The Gries while-loop task set used to train the ML models — 3,000 records, 4 columns (Description, Solution, Feedback, Label), prepared only from the base paper's referenced repositories.

📚 Sources (base paper, references page)

[25] IBM Project CodeNet — github.com/IBM/ProjectCodeNet — large-scale AI-for-code benchmark
[26] Codeforwin — codeforwin.org — beginner programming exercises with loops
[27] PYnative — pynative.com — Python tutorials, exercises and quizzes

Following paper §II-A: 20 canonical beginner while-loop tasks in the style of these repositories were compiled and augmented (paper's Prompt-1 data-augmentation scheme) to 3,000 records with logic errors injected into exactly the S / T / E Gries states — no syntax errors. Distribution: 29% S · 29% E · 29% T · 4% each pair · 3% all three.
